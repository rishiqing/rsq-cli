## 功能

- 通过命令行管理任务、项目、流程、OKR、复盘、绩效、文档和数据表等日事清业务。
- 支持账号密码和浏览器扫码登录，多账号可通过 profile 分别保存会话。
- 提供逐级 Schema、结构化 JSON 输出和 Agent Skill。
- 提供 macOS、Linux、Windows 的 x64 / ARM64 安装包，自带运行时。
- 支持检查更新、自升级和版本回滚，保留已有登录会话。

## 安装与更新

安装命令见[安装指南](https://github.com/rishiqing/rsq-cli/blob/main/docs/install.md)。已安装的用户可执行：

```sh
rsq upgrade --yes
```

本页 Assets 提供各平台安装包、安装脚本和 `SHA256SUMS` 校验文件。

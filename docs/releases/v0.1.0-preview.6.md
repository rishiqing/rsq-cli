## 改进

- 简化安装步骤：macOS / Linux 使用一行命令安装；命令路径由安装脚本按需配置。
- 完善登录、业务操作、Agent 接入和升级的使用指南。
- 提供业务模块的 Schema 导航，便于发现命令和参数。

## 安装

macOS / Linux：

```sh
curl -fsSL https://raw.githubusercontent.com/rishiqing/rsq-cli/main/scripts/install.sh | sh
```

Windows（PowerShell）：

```powershell
irm https://raw.githubusercontent.com/rishiqing/rsq-cli/main/scripts/install.ps1 | iex
```

## 更新

```sh
rsq upgrade --yes
```

安装包自带运行时，支持 macOS、Linux、Windows 的 x64 / ARM64。升级保留已有登录会话；各平台安装包及 `SHA256SUMS` 校验文件见本页 Assets。
